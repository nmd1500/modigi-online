高級革小物でよく耳にする「スイフト」と「エプソン」。どちらも仔牛（ヴォー）の革ですが、仕上げ方の違いによって、まったく異なる個性を持っています。

## ひと目でわかる違い

| | ヴォー・スイフト | ヴォー・エプソン |
|---|---|---|
| 表面 | なめらか・マット | 細かな型押し |
| 手ざわり | しっとり柔らか | さらりと軽い |
| 傷への強さ | ふつう | 強い |
| 型崩れ | 馴染んで手首に沿う | 形をキープしやすい |
| 経年変化 | 艶が増し、しなやかに | 変化は穏やか |

## ヴォー・スイフト — 手に吸い付く、しなやかさ

スイフトは、革の表面を浅くマットに仕上げたカーフレザー。手に吸い付くようなしっとりとした質感と、ほどよい弾力が特長です。

色の発色がとても美しく、オレンジやグリーンといった鮮やかなカラーも上品に見せてくれます。使い込むほどに柔らかさと艶が増し、手首の形に沿って馴染んでいくのも魅力です。

**こんな方におすすめ：** 着け心地を最優先したい方、革が育っていく変化を楽しみたい方。

## ヴォー・エプソン — 凛とした、タフな美しさ

エプソンは、カーフの表面に細かな型押しを施した革。型押しによって表面が引き締まり、軽く、傷や水に強いのが最大の特長です。

シャープな見た目を長く保てるため、きちんとした印象を求めるビジネスシーンにもぴったり。コントラストの効いたステッチとの相性もよく、端正なシルエットが際立ちます。

**こんな方におすすめ：** 毎日アクティブに使いたい方、新品のような美しさを長く保ちたい方。

## 迷ったときは

「柔らかさ」を取るならスイフト、「タフさ」を取るならエプソン。どちらも裏地には防水加工のカーフを合わせているため、日常使いの快適さに大きな差はありません。
